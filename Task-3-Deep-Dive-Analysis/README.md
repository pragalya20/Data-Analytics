#  Deep-Dive Analysis & Interactive Dashboarding

##  Project Overview
This project focuses on performing a deep-dive business analysis on sales data and building an interactive dashboard using Power BI.

The analysis explores regional sales performance, product category trends, customer payment behavior, and monthly sales patterns.

---

##  Objectives
- Define core business KPIs
- Perform deep-dive analysis on regional sales
- Build an interactive BI dashboard
- Generate business insights for decision-making

---

##  Dataset Features
- Transaction ID
- Date
- Product Category
- Product Name
- Units Sold
- Unit Price
- Total Revenue
- Region
- Payment Method

---

##  Core KPIs
1. Total Revenue
2. Average Revenue per Order
3. Total Orders
4. Top Performing Region
5. Top Product Category

---

##  Dashboard Features
### Page 1 — Executive Overview
- KPI Cards
- Revenue by Region
- Monthly Sales Trend

### Page 2 — Deep-Dive Analysis
- Revenue by Product Category
- Payment Method Analysis
- Interactive Slicers

---

##  Key Insights
- North America generates the highest revenue.
- Electronics is the top-performing category.
- Credit cards are the preferred payment method.
- Monthly sales fluctuate across regions.
- Interactive filtering improves business exploration.

---

##  Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Power BI
- SQL

---

##  Conclusion
This project demonstrates how business intelligence tools and data analysis can be used to uncover patterns, monitor KPIs, and support data-driven decision-making.
